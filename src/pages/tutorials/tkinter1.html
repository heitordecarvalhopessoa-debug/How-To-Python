Use Tkinter

Learn how to create desktop windows with Python, customize their appearance, and display text using labels.

1. What Is Tkinter?

Tkinter is a Python library used to create graphical user interfaces (GUIs). It allows you to build desktop applications with windows and visual elements.

With Tkinter, you can create:

  • Application windows.
  • Text labels.
  • Buttons.
  • Input fields.
  • Menus and other interface elements.

Tkinter is usually included with Python. If it is missing, you may need to install the appropriate package for your operating system.

2. Importing Tkinter

Before using Tkinter, you need to import the library into your Python program. 

import tkinter as tk

Understanding the Code

  • import tells Python to load a module or library.
  • tkinter is the name of the library we want to use.
  • as tk gives the library a shorter name, making the code easier to write.

After importing it, you can use tk to access Tkinter features.

3. Creating Your First Window

Every basic Tkinter application starts by creating a main window. 

import tkinter as tk

window = tk.Tk()

window.mainloop()

Understanding the Code

window = tk.Tk()

This line creates the main application window.

  • window is the variable that stores the window object.
  • = assigns the created object to the variable.
  • tk.Tk() creates the main Tkinter application window.

window.mainloop()

This starts Tkinter's event loop. It keeps the window running and allows the application to respond to user interactions.

4. Customizing the Window

Tkinter provides several methods for changing a window's title, size, background color, and dimensions.

4.1. Changing the Window Title

window.title("My Application")

The title() method sets the text displayed in the window's title bar.

4.2. Changing the Window Size

window.geometry("800x500")

The geometry() method sets the initial window dimensions.

  • 800 is the width in pixels.
  • 500 is the height in pixels.

You can also specify the initial screen position:

window.geometry("800x500+100+50")

The last two numbers specify the approximate horizontal and vertical position of the window.

4.3. Changing the Background Color

window.configure(bg="black")

The configure() method changes properties of the window. The bg parameter means background color.

You can use named colors:

window.configure(bg="white")
window.configure(bg="black")
window.configure(bg="red")
window.configure(bg="blue")
window.configure(bg="green")

You can also use hexadecimal color codes:

window.configure(bg="#20242b")

Hexadecimal colors let you choose more specific shades, such as dark gray, blue, or green.

4.4. Disabling Window Resizing

window.resizable(False, False)

The resizable() method controls whether the user can resize the window.

  • The first value controls the width.
  • The second value controls the height.
  • False disables resizing.
  • True allows resizing.

4.5. Setting the Minimum Size

window.minsize(400, 300)

This sets the minimum window size to 400 pixels wide and 300 pixels tall.

4.6. Setting the Maximum Size

window.maxsize(1200, 800)

This sets the maximum window size to 1200 pixels wide and 800 pixels tall.

5. Adding a Label

A Label is a Tkinter widget used to display text or an image inside a window. 

import tkinter as tk

window = tk.Tk()

window.title("My Application")
window.geometry("600x400")
window.configure(bg="black")

text = tk.Label(
    window,
    text="Hello, world!",
    font=("Arial", 20),
    fg="white",
    bg="black"
)

text.pack()

window.mainloop()

Understanding the Label

tk.Label()

Creates a new Label widget.

window

Specifies the parent window where the Label will be displayed.

text="Hello, world!"

Defines the text displayed by the Label.

font=("Arial", 20)

Sets the font family to Arial and the font size to 20.

fg="white"

Sets the text color. The abbreviation fg means foreground.

bg="black"

Sets the Label's background color.

text.pack()

The pack() method places the Label inside the window using Tkinter's layout system.

6. Positioning a Label

The pack() method has options for positioning widgets and adding spacing.

Default Position

text.pack()

By default, the widget is placed horizontally centered in the available area, following the order in which widgets are packed.

Placing the Label at the Top

text.pack(side="top")

Placing the Label at the Bottom

text.pack(side="bottom")

Adding Spacing

text.pack(pady=20, padx=10)
  • pady=20 adds vertical spacing.
  • padx=10 adds horizontal spacing.

These spacing values are measured in pixels.

7. Further Label Customization

7.1. Changing the Text Color

text = tk.Label(
    window,
    text="Colored Text",
    fg="yellow",
    bg="#20242b"
)

text.pack()

7.2. Using a Larger Font

text = tk.Label(
    window,
    text="Application Title",
    font=("Arial", 28, "bold")
)

text.pack()

The "bold" option makes the text bold. You can also use "italic" for italic text.

7.3. Aligning Text to the Left

text = tk.Label(
    window,
    text="Text aligned to the left",
    anchor="w",
    width=35
)

text.pack()

The anchor parameter controls the position of the content inside the Label's available area.

  • "w": left.
  • "e": right.
  • "center": center.
  • "n": top.
  • "s": bottom.

The width option is measured in text units, not necessarily pixels.

8. Complete Example

Now let's combine everything into one complete program. 

import tkinter as tk

window = tk.Tk()

window.title("My First Application")
window.geometry("700x450")
window.configure(bg="#20242b")
window.resizable(False, False)

title = tk.Label(
    window,
    text="My First Application",
    font=("Arial", 24, "bold"),
    fg="white",
    bg="#20242b"
)

title.pack(pady=30)

description = tk.Label(
    window,
    text="This window was created with Python and Tkinter.",
    font=("Arial", 12),
    fg="#c5cbd3",
    bg="#20242b"
)

description.pack(pady=10)

information = tk.Label(
    window,
    text="Learning to create graphical interfaces.",
    font=("Arial", 10, "italic"),
    fg="#7ccba2",
    bg="#20242b"
)

information.pack(pady=5)

window.mainloop()

What Does This Program Do?

  1. Imports Tkinter.
  2. Creates the main window.
  3. Sets the title and window size.
  4. Changes the background color.
  5. Disables window resizing.
  6. Creates three Labels with different styles.
  7. Arranges the text using pack().
  8. Starts the event loop.

9. Command Reference

Command Purpose
import tkinter as tk Imports the library.
tk.Tk() Creates the main window.
window.title() Sets the window title.
window.geometry() Sets the window size and optional position.
window.configure() Changes window properties.
window.resizable() Controls window resizing.
window.minsize() Sets the minimum window size.
window.maxsize() Sets the maximum window size.
tk.Label() Creates a text or image widget.
text.pack() Places a widget in the interface.
window.mainloop() Runs the interface event loop.

10. Running Your Program

  1. Install Python if you have not already.
  2. Open a code editor, such as Visual Studio Code.
  3. Create a file named main.py.
  4. Copy the complete example into the file.
  5. Open a terminal in the directory containing the file.

Run the program with:

python main.py

On Windows, you can also try: 

py main.py

If Python reports that Tkinter is missing, check whether your Python installation includes the Tkinter package.
