Python Basics: Conditions and Comparisons

Learn how to make Python choose what to do based on conditions.

1. What Is a Condition?

A condition is an expression that evaluates to either True or False. Python can use it to decide which code should run.

age = 18

if age >= 18:
    print("You are an adult.")

Understanding the Code

age = 18 stores the number 18 in a variable.

if begins a conditional statement.

age >= 18 checks whether age is greater than or equal to 18.

The colon (:) marks the beginning of the block, and indentation identifies the code inside it.

print() runs only if the condition is true.

2. Comparison Operators

3. Using else

The else block runs when the if condition is false.

temperature = 12

if temperature > 20:
    print("It is warm.")
else:
    print("It is cold.")

Because 12 is not greater than 20, Python prints It is cold.

4. Using elif

elif means "else if". It lets you check another condition when the earlier condition was false.

score = 75

if score >= 90:
    print("Grade A")
elif score >= 70:
    print("Grade B")
else:
    print("Grade C")

Python checks the conditions from top to bottom. Here, the result is Grade B.

5. Combining Conditions

You can combine multiple conditions using and, or, and not.

age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("Access allowed.")

if age < 18 or not has_ticket:
    print("Access denied.")
  • and requires both conditions to be true.
  • or requires at least one condition to be true.
  • not reverses a Boolean value.

6. Checking Text

Conditions can also compare strings.

password = "python"

if password == "python":
    print("Correct text.")
else:
    print("Incorrect text.")

String comparisons are case-sensitive, so "Python" and "python" are different strings.

7. Indentation Matters

Python uses indentation to identify which statements belong to a condition.

number = 10

if number > 5:
    print("This line is inside the if block.")

print("This line runs afterward.")

The first message appears only if the condition is true. The second message runs regardless of that condition.

Practice

  1. Create a variable called number.
  2. Use if to check whether it is positive.
  3. Use else to handle the other case.
  4. Use elif to check whether the number is zero.

Summary

  • if checks a condition.
  • elif checks another condition.
  • else handles the remaining case.
  • Comparison operators compare values.
  • and, or, and not combine or reverse conditions.
