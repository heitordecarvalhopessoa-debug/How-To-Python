Tkinter: Buttons and Functions

In this tutorial, you will learn how to create buttons, define functions, and make your Tkinter applications interactive.

1. What Is a Button?

A button is a graphical element that the user can click to perform an action. In Tkinter, buttons are created using Button(). 

import tkinter as tk

window = tk.Tk()
window.title("My Application")
window.geometry("400x300")

button = tk.Button(window, text="Click Me")
button.pack()

window.mainloop()

Understanding the Code

import tkinter as tk

Imports the Tkinter library and gives it the shorter name tk. This lets us write tk.Button() instead of tkinter.Button().

window = tk.Tk()

Creates the main application window. All the widgets, such as buttons and labels, will be placed inside this window.

window.title("My Application")

Sets the text displayed in the window's title bar.

window.geometry("400x300")

Sets the window size to 400 pixels wide and 300 pixels tall. The format is "widthxheight".

button = tk.Button(window, text="Click Me")

Creates a button inside window. The text parameter defines the words shown on the button.

button.pack()

Places the button in the window. Without a geometry manager such as pack(), the button will not appear.

window.mainloop()

Starts Tkinter's event loop. It keeps the window open and waits for user actions, such as clicks.

2. What Is a Function?

A function is a reusable block of code that performs a specific task. In Python, functions are defined with the def keyword. 

def say_hello():
    print("Hello, world!")

say_hello()

Understanding the Code

def

Tells Python that you are defining a function.

say_hello

Is the function's name. You choose a name that describes what the function does.

()

The parentheses can contain parameters, which allow a function to receive information. Here, they are empty.

:

The colon marks the beginning of the function body. The indented lines below it belong to the function.

print("Hello, world!")

Displays the text in the Python console when the function runs.

say_hello()

Calls the function. Defining a function does not execute it automatically; you must call it.

3. Connecting a Button to a Function

The command parameter connects a button to a function. When the user clicks the button, Tkinter calls that function. 

import tkinter as tk

def say_hello():
    print("Hello, world!")

window = tk.Tk()
window.title("Button Example")
window.geometry("400x300")

button = tk.Button(
    window,
    text="Say Hello",
    command=say_hello
)

button.pack(pady=20)

window.mainloop()

Understanding the Code

def say_hello():

Defines the function that will run when the button is clicked.

command=say_hello

Tells Tkinter which function to call when the button is pressed. Notice that there are no parentheses after say_hello.

Writing command=say_hello() would call the function immediately while creating the button, rather than passing the function for a future click.

button.pack(pady=20)

Places the button in the window and adds 20 pixels of vertical padding around it.

4. Changing a Label with a Button

A button can change something inside the window instead of only printing text in the console. For example, it can update a label. 

import tkinter as tk

def change_text():
    label.config(text="The button was clicked!")

window = tk.Tk()
window.title("Changing Text")
window.geometry("400x300")

label = tk.Label(window, text="Click the button below")
label.pack(pady=20)

button = tk.Button(
    window,
    text="Change Text",
    command=change_text
)

button.pack()

window.mainloop()

Understanding the Code

label = tk.Label(window, text="Click the button below")

Creates a label, which is a widget used to display text inside the window.

label.config(text="The button was clicked!")

Updates the label's text. The config() method can change a widget's options after it has been created.

When the button is clicked, Tkinter calls change_text(), and the label displays the new message.

5. Functions with Parameters

Parameters let a function receive information. This makes the same function useful for different values. 

def greet(name):
    print("Hello, " + name + "!")

greet("Alex")
greet("Sam")

The output will be:

Hello, Alex!
Hello, Sam!

Understanding the Code

name

Is a parameter. It receives the value passed when the function is called.

greet("Alex")

Calls the function with "Alex" as the argument. Inside the function, name contains that text.

6. Passing Arguments to a Button

Tkinter normally calls a button's command function without arguments. To pass a value, you can use lambda. 

import tkinter as tk

def greet(name):
    label.config(text="Hello, " + name + "!")

window = tk.Tk()
window.title("Greeting App")
window.geometry("400x300")

label = tk.Label(window, text="Click a button")
label.pack(pady=20)

button = tk.Button(
    window,
    text="Greet Alex",
    command=lambda: greet("Alex")
)

button.pack()

window.mainloop()

What Is Lambda?

lambda creates a small anonymous function. In this example, it waits for the button click before calling greet("Alex").

Without lambda, calling greet("Alex") directly in the command parameter would execute the function immediately.

7. Customizing Buttons

Tkinter buttons have parameters that control their appearance, including background color, text color, font, and size. 

import tkinter as tk

window = tk.Tk()
window.title("Custom Button")
window.geometry("400x300")

button = tk.Button(
    window,
    text="Start",
    bg="#2463a6",
    fg="white",
    font=("Arial", 12),
    width=15,
    height=2
)

button.pack(pady=30)

window.mainloop()

Understanding the Parameters

bg="#2463a6"

Sets the button's background color.

fg="white"

Sets the button text color.

font=("Arial", 12)

Sets the font family to Arial and the font size to 12.

width=15

Sets the button width in text units.

height=2

Sets the button height in text units.

8. Common Button Parameters

Parameter Purpose
text Sets the text displayed on the button.
command Specifies the function called when clicked.
bg Sets the background color.
fg Sets the text color.
font Sets the font family and size.
width Sets the button width.
height Sets the button height.
state Controls whether the button is enabled or disabled.
padx Adds horizontal internal padding.
pady Adds vertical internal padding.

9. Practice Exercise

Create a window with the following elements:

  1. A label displaying "Welcome!".
  2. A button named "Change Message".

Try to write the code yourself before looking at the examples again. This is a good way to practice functions and button callbacks.

10. Summary

  • Button() creates a clickable button.
  • def defines a function.
  • command connects a button to a function.
  • config() changes a widget's properties.
  • lambda helps pass arguments to a callback.
  • Label() displays text in a window.
