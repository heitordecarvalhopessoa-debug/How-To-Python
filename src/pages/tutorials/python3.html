Python Basics: Loops

Learn how to repeat instructions using Python's for and while loops.

1. What Is a Loop?

A loop repeats a block of code. Loops are useful when you want to perform the same task multiple times without writing the same instructions repeatedly.

2. The for Loop

A for loop can repeat an action for each item in a sequence.

for number in range(5):
    print(number)

Understanding the Code

for begins the loop.

number is the variable that receives each value during the loop.

range(5) produces the numbers 0, 1, 2, 3, and 4.

print(number) displays the current value on each repetition.

The output is:

0
1
2
3
4

3. Understanding range()

The built-in range() function creates a sequence of integers. The ending value is excluded.

for number in range(1, 6):
    print(number)

This prints the numbers from 1 to 5. The first argument is the starting value, and the second is the stopping value.

You can also specify a step:

for number in range(0, 10, 2):
    print(number)

The output is 0, 2, 4, 6, and 8. The third argument tells Python to increase the number by 2 each time.

4. Looping Through a String

A string is a sequence of characters, so a for loop can visit each character.

word = "Python"

for letter in word:
    print(letter)

Each repetition assigns the next character to letter.

5. The while Loop

A while loop repeats as long as its condition remains true.

count = 1

while count <= 5:
    print(count)
    count = count + 1

Understanding the Code

count = 1 sets the initial value.

while count <= 5: repeats the block while count is less than or equal to 5.

print(count) displays the current number.

count = count + 1 increases count by one each time.

Updating count allows the condition to eventually become false. Without an appropriate update, the loop could run forever.

6. Using break

The break statement immediately ends the loop.

for number in range(10):
    if number == 5:
        break

    print(number)

The loop stops when number reaches 5, so the output contains 0 through 4.

7. Using continue

The continue statement skips the rest of the current repetition and moves to the next one.

for number in range(5):
    if number == 2:
        continue

    print(number)

The number 2 is skipped, so the output is 0, 1, 3, and 4.

8. Nested Loops

A nested loop is a loop inside another loop.

for row in range(3):
    for column in range(2):
        print(row, column)

For every value of row, the inner loop visits both values of column.

9. for vs. while

LoopBest used for
for Iterating through a sequence or a known range of values.
while Repeating while a condition remains true.

Practice

  1. Use a for loop to print numbers from 1 to 10.
  2. Use a while loop to count from 5 down to 1.
  3. Print every character in your name.
  4. Use continue to skip one number in a loop.

Summary

  • for repeats over a sequence.
  • range() generates a sequence of integers.
  • while repeats while a condition is true.
  • break ends a loop.
  • continue skips to the next repetition.
