Python Basics: Variables and Data Types

Learn how to store information and work with different types of data in Python.

1. What Is a Variable?

A variable is a name used to store a value. You can create one by writing its name, followed by an equals sign and a value.

name = "Alex"
age = 15
is_learning = True

print(name)
print(age)
print(is_learning)

Understanding the Code

name = "Alex" creates a variable named name and stores the text "Alex".

age = 15 stores the integer number 15.

is_learning = True stores a Boolean value, which can be either True or False.

print() displays a value in the console.

2. Strings

A string is text written between quotation marks.

first_name = "Alex"
message = 'Hello!'
print(first_name)
print(message)

You can use single or double quotation marks to create strings. The opening and closing quotation marks must match.

3. Numbers

Python supports integers and floating-point numbers.

apples = 5
price = 2.50

print(apples)
print(price)

5 is an integer (int). The value 2.50 is a floating-point number (float).

4. Basic Math

You can use Python to perform mathematical operations.

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
OperatorMeaningExample
+Addition10 + 3 = 13
-Subtraction10 - 3 = 7
*Multiplication10 * 3 = 30
/Division10 / 3 gives a decimal result
//Floor division10 // 3 = 3
%Remainder10 % 3 = 1

5. Joining Text

You can combine strings using the + operator.

name = "Alex"
print("Hello, " + name + "!")

Output: Hello, Alex!

You can also use an f-string, which lets you insert variable values inside text.

name = "Alex"
age = 15

print(f"My name is {name} and I am {age}.")

Put the letter f before the quotation mark and place variable names inside curly braces.

6. Checking Data Types

The built-in type() function tells you the type of a value.

print(type("Hello"))
print(type(10))
print(type(2.5))
print(type(True))

The results correspond to str, int, float, and bool.

Practice

  1. Create a variable named city and store a city name.
  2. Create two number variables and print their sum.
  3. Use an f-string to display a message containing a variable.

Summary

  • Variables store values.
  • Strings store text.
  • Integers and floats store numbers.
  • Booleans represent True or False.
  • print() displays information.
